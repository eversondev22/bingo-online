# 🎯 Partiu Bingo

## Plataforma Web de Bingo Online

O **Partiu Bingo** é um projeto pessoal em desenvolvimento, criado com o objetivo de desenvolver uma plataforma web de bingo online voltada à interação entre pessoas e comunidades.

O projeto também faz parte da minha formação prática em **Análise e Desenvolvimento de Sistemas (ADS)** e dos meus estudos em desenvolvimento de software.

## 🚀 Tecnologias utilizadas

- JavaScript
- Node.js
- Express
- PostgreSQL
- bcrypt
- API REST

## 🔧 Backend

O backend está sendo desenvolvido utilizando **Node.js e Express**, com integração ao banco de dados **PostgreSQL**.

Atualmente, o projeto contempla conceitos como:

- Criação de APIs REST
- Operações CRUD
- Rotas
- Controllers
- Models
- Integração com banco de dados relacional
- Validação de dados
- Tratamento de erros
- Criptografia de senhas com bcrypt
